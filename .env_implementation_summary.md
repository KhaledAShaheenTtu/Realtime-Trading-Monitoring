## 🔧 Configuration Features:

### **Environment Variables Available:**
```env
# API Keys
FRED_API_KEY=                    # Federal Reserve data
ALPHA_VANTAGE_API_KEY=          # Alternative financial data
COINDESK_API_KEY=               # News data (free tier available)

# TradingView (optional)
TRADINGVIEW_USERNAME=
TRADINGVIEW_PASSWORD=

# Collection Settings
COLLECTION_INTERVAL=300         # 5 minutes
NEWS_FETCH_LIMIT=1

# File Paths (all configurable)
DATA_DIR=data
BTCUSDT_FILE=data/btcusdt.csv
TONUSDT_FILE=data/tonusdt.csv
MAG7_FILE=data/mag7.csv
FED_RATES_FILE=data/fed_rates.csv
NEWS_FILE=data/news.csv
FILINGS_FILE=data/sec_filings_combined.csv

# System Settings
LOG_LEVEL=INFO
ENVIRONMENT=development
MAX_RETRIES=3
RETRY_DELAY=5
```

- ✅ **Validation**: Checks for missing critical settings
- ✅ **Fallback Values**: Works without API keys
- ✅ **Type Conversion**: Handles strings, integers, booleans
- ✅ **Environment Detection**: Development vs Production modes
